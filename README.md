# SCAD → 3D

OpenSCADコードを貼り付け、ブラウザで3D形状を確認し、STLを保存する静的Webアプリです。モデル処理は端末内で完結します。共通パスワードの認証ゲートを実装済みです。[公開サイト](https://scad-to-3d-private.pages.dev/) をCloudflare Freeでパスワード付き限定提供しています。費用と認証設定は下記の運用文書を参照してください。

## 起動

開発用Node.js 22.12以降とnpmが必要です。利用者の端末にはブラウザだけで構いません。

```sh
npm ci
npm run dev
```

表示されたローカルURLを開きます。初回 `npm ci` では公式の固定版OpenSCAD WASMを取得し、公開SHA-256と照合します。取得失敗時はネットワークを確認して `npm run build` を再実行してください。開発サーバーはデフォルトでローカル端末のみから利用できます。

## 使い方

1. 任意のAIから取得したSCADコードを左側へ貼り付けます。Markdownのコード囲みは除きます。
2. **3Dモデル生成**を押します。初回はエンジンのロードが必要です。
3. ドラッグで回転、ホイールでズーム、右ドラッグでパン。タッチでは1本指で回転、2本指でズーム・パンします。7つの視点ボタンと全体表示も使えます。
4. **STLをダウンロード**を押し、Bambu Studio等でmmとして開きます。

コードの編集後は再生成が必要です。前のプレビューには「変更が未反映」と表示され、STL保存ボタンが無効になります。エラー時は日本語の案内とOpenSCADの原文が表示されます。生成中に編集しても処理対象は押下時点のコードで固定されます。

プレビューの「目盛り」でcm/mmを切り替えられます。床面の定規、グリッド1マスの大きさ、モデルのX・Y・Z寸法が選択した単位で表示されます。表示単位を切り替えてもコードとSTLの寸法はmmのままです。サンプルの「大きめの収納ボックス」は22×14×8cmで、大きな形状も自動的に全体が収まります。

コピー・貼り付け・全選択・Undo/Redoは標準textareaのOS操作を利用できます。Ctrl/Cmd+Enterでも生成できます。「クリア」は標準編集履歴を保つ削除を試み、対応しないブラウザでは全選択まで行い削除キーを案内します。コードの自動保存はありません。

「コード保存」またはCtrl/Cmd+Sで編集中のコードを `.scad` ファイルとして保存できます。「開く」でUTF-8のSCADファイル（200KB以下）を読み込めます。編集中の内容がある場合は置換前に確認します。不正な形式・読み込み失敗・過大な貼り付けでは元のコードを残します。共有端末に入力内容を残さないためブラウザへの永続保存はしません。

3D表示が停止した場合は「3D表示を再開」で、コードと生成済みモデルを残してビューアを再作成します。表示の再開はメモリ不足によるタブ自体の終了までは復旧できません。

## ビルドと配布

```sh
npm run build
npm run preview
```

`dist/` が静的配信対象です。`file://` ではなくHTTP(S)で配信してください。特殊なCOOP/COEPヘッダーは不要です。

**共通パスワードで限定公開します。** 公開用ビルドには全パスを保護するCloudflare Pages認証ゲートを含みます。Workers Free契約を管理画面で確認し、本番・プレビュー両方をFail closedに設定済みです。OpenSCADの依存ソース照合の残件は [来歴](docs/engine-provenance.md) を参照してください。

[限定提供と費用0円の条件](docs/private-deployment.md) を参照してください。パスワード保護のローカル確認は `npm run preview:protected`（127.0.0.1:8788）で行います。`npm run preview` と `npm run dev` はUI開発用で認証はありません。`dist` を汎用静的ホストへ置くだけでは認証されません。

## 検証

```sh
npm test
npx playwright install chromium webkit
npm run build
npm run test:e2e
```

E2Eは開発サーバーではなく `dist/` を検証します。実WASMで17種類のモデルを生成し、ダウンロードしたSTLの三角形数・サイズ・有限座標・体積をチェックします。ChromiumとWebKit（iPad画面設定）を利用します。実端末での確認状況とスライサーの結果は [検証結果](docs/verification.md) を参照してください。

## 制限とプライバシー

- コード200KB、生成60秒、STL25MB、ログ64KBが上限です。中止はWorkerを終了します。ページを離れると実行中の処理を中止します。
- `include` / `use` / `import` / `surface` は禁止。ファイルやライブラリはマウントしません。フォント同梱がないためtextを使うモデルも対象外です。2Dは押し出し等で3Dにしてください。
- 入力とSTLはサーバー、アクセス解析、localStorageへ送信・保存しません。エンジンとアプリは同一originから取得します。ホストには通常のファイルアクセスログが残り得ます。
- Workerはメモリ消費によるタブ終了を完全には防げません。iPad等では低い `$fn` から試してください。厳密なメモリ上限にはWASMの再ビルドが必要です。
- 最新Chrome/Edge/SafariとWebGL2が対象です。実験版WASMのためデスクトップOpenSCADとすべての機能が同一とは保証しません。スライサーでの強度・印刷設定は別途確認してください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `src/main.ts` | UI・生成snapshot・保存・状態管理 |
| `src/source-file.ts` | SCADファイル検証・読み込み・ローカル保存 |
| `src/engine.ts` | Workerの寿命、中止、時間制限 |
| `src/scad.worker.ts` | OpenSCAD本体の実行、STL出力 |
| `src/policy.ts` | 外部参照の制限、日本語エラー案内 |
| `src/viewer.ts` | STL検証、Three.js、カメラ操作、GPU解放 |
| `src/examples.ts` | ブラケット、スタンド、ホルダー、基本形状 |
| `scripts/prepare-assets.mjs` | 固定エンジンの検証・配置、ライセンス同梱 |
| `docs/architecture.md` | 実装前調査・選定・データフロー・一次資料 |

将来はWorkerの出力形式とビューア入力を追加することで拡張できます。現時点ではSTLだけを扱い、3MF/STEPや計測機能は含めません。
