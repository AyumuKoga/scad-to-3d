# note有料記事での利用案内：規約・ライセンス確認

確認日：2026-09-24。日本在住の運営者が、日本の一般消費者向けに、自分で運営するSCAD → 3Dの利用用URL・共通認証情報をnote有料記事で提供する想定。公開資料に基づく整理で、弁護士の法的意見・各社の個別承認ではない。

## 判定

**2026-09-25の技術面の更新：** 記録済みソースからエンジンを再ビルドし、依存ソース・ライセンス・ビルド手順をGitHubと配布サイトから提供する形へ更新した。以下の「未完了」は2026-09-24の調査時点の記録。現行の配布状態は [来歴](engine-provenance.md)、掲載用の本文は [短い文案](note-license-disclosure.md) を参照。noteの個別承認や販売表示の記入まで完了したという意味ではない。

方式の一律禁止は確認できない。ただし、現状はOpenSCADの対応ソース提供が未完了であり、販売開始を推奨しない。有料化の有無にかかわらず、現在のブラウザ向けWASM配布にも関係する問題。販売や公開停止の操作は今回の調査では行っていない。

## note

[note規約](https://note.com/terms)のクリエイター規約1.1は有料提供を認め、6.9はパスワード付き外部サイトも内容確認対象として想定する。一方、これは個別の売り方の承認ではない。総則17のアカウント情報の定義から、note自身のログイン情報の共有と今回のアプリ用認証は区別して読むのが妥当と考える。ただし、クリエイター規約9.1(13)にはオンラインゲーム等のアカウント譲渡禁止があり、自作サービスへの共通アクセス許可という今回の形への適用についてはnoteへの個別確認を勧める。知的財産侵害とそのリンク先も禁止対象。

問い合わせ文案（未送信、実パスワードの記載は不要）：

> 自分が運営するOpenSCADベースのブラウザアプリについて、有料記事の購入者に、記事の有料部分で外部サイトのURLと共通の利用用ID・パスワードを案内したいと考えています。noteやCloudflareのアカウントを譲渡するものではなく、自作サービスへのアクセスを許可するものです。決済はnoteだけで行い、外部サイトで追加決済は行いません。提供内容・利用期間・制限・停止時の対応・返金条件を購入前に記載します。この形はクリエイター規約9.1(13)のアカウント譲渡等に該当しますか。ほかに必要な条件はありますか。

## Cloudflare

[Self-Serve契約](https://www.cloudflare.com/terms/)2.2.1(a)はCloudflareサービスそのものへのアクセス販売を制限する。今回は自作アプリを提供し、Cloudflareアカウント・API・ホスティング権限を渡さないため、通常のアプリ運営に当たると読むのが妥当。ただし個別の公式承認ではない。Freeの商用利用を一律に禁止する条項は確認できなかった。

2.2.1(h)はFree利用サイトでのカード情報の収集・処理を制限する。今回の決済はnote側だけで行う想定。2.6は無料サービスの終了可能性を定める。[Developer Platform規約](https://www.cloudflare.com/service-specific-terms-developer-platform/)は、第三者ソフトのライセンス遵守、利用者対応等を運営者の責任とする。pages.dev名の変更可能性もある。無料・永久・無停止の運営を保証する根拠にはならない。

## OpenSCAD / GPL

[GNU GPL FAQ](https://www.gnu.org/licenses/gpl-faq.en.html#DoesTheGPLAllowMoney)では有料配布を認める。[GPLv2第3条](https://www.gnu.org/licenses/old-licenses/gpl-2.0.en.html#section3)は実行形式配布に対応ソース等の条件を課す。今回、エンジンを利用者のブラウザへダウンロードさせているので、サーバー内部でのみ実行する場合と異なる。

アプリソースとOpenSCAD本体の該当revisionは提供済みだが、実際にリンクされた依存ソース・パッチ等の確定は未完了。[来歴](engine-provenance.md)を参照。上流トップページへのリンクや「未完了」の表示で不足が解消するわけではない。対応ソースを確保するか、ソース一式を固定して再ビルドする必要がある。全く同じバイト列の再現が独立の必須条件だという判断ではなく、必要な対応ソースの不足が問題である。

購入者にGPL対象コードの改変・再配布等を一律禁止できない。記事本文やホストへのログイン情報の取扱いと、GPLで付与されるソフトウェアの権利は区別して規定する。記事のおまけという呼び方でもWASM配布の条件は変わらない。

## 日本向け販売表示・運用

[消費者庁の通信販売Q&A](https://www.no-trouble.caa.go.jp/qa/advertising.html)は有料情報配信等の役務を対象に含める。[noteの特商法案内](https://www.help-note.com/hc/ja/articles/360008947533)によると、営利の意思をもって反復継続する販売は販売業者・役務提供事業者に該当し得る。個人だから当然に対象外とはしない。

購入前に、何を販売するか、提供開始・期間、対応環境、200KB・60秒等の機能制限、無料枠による停止可能性、サポート範囲、終了・認証情報変更時の案内、解約・返金条件、必要な事業者表示を具体化する。[消費者庁の広告表示案内](https://www.caa.go.jp/policies/policy/representation/fair_labeling/representation_regulation/internet)を参照。『永久利用』『無制限』『絶対に止まらない』を現状で約束しない。『一切責任を負わない』だけで法的責任が消えるとは扱わない（[消費者契約法の案内](https://www.caa.go.jp/policies/policy/consumer_system/consumer_contract_act/)）。

技術的には共通認証なので購入者の識別・個別失効・返金者だけのアクセス取消しはできない。パスワード変更は全員に影響する。販売数と利用者数は一致しない。

Cloudflare Freeでは認証を通る全HTTPリクエストがアカウント共通の1日10万回枠に算入される。Fail closedを設定済みなので超過時は停止する。[料金資料](https://developers.cloudflare.com/pages/functions/pricing/)。

『ホスティング0円』と『販売コスト0円』は異なる。[note手数料](https://www.help-note.com/hc/ja/articles/360011358873)が売上から差し引かれる。例：1,000円の記事をカードで購入した場合、事務手数料50円とプラットフォーム料95円、さらに売上振込1回につき270円。所得等に応じた税務の確認も別途必要。

## 販売前に残る作業

1. 対応ソースと依存ライセンスを整備し、現在の配布の問題を解消する。
2. 上記の具体的な販売形態についてnoteの回答を得る。Cloudflareの解釈にも契約上の確証が必要なら同社にも確認する。
3. 実際の商品説明・提供期間・返金条件・特商法表示を作成し、実装と一致させる。商品説明の最終案は今回未提示のため未審査。
4. 継続的な有料サービスとして始める場合、必要に応じて日本法とOSSに詳しい弁護士に最終確認を依頼する。
