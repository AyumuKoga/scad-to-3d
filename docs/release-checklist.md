# 限定提供前の条件

共通パスワードを知るユーザー向けに限定提供する。このアプリの運用費用は0円を必須条件とする。ユーザーの外部公開指示に基づきCloudflare Pagesへ配置済み。公開先は https://scad-to-3d-private.pages.dev/ 。

## 認証と費用（配布前の必須条件）

- [x] 共通パスワードの自動生成をユーザーが選択。
- [x] サーバー側の全パス認証、Secret不備・エラー時の拒否を実装。
- [x] Chromium/WebKitで未認証の拒否と認証後の実WASM生成・STL保存を検証。
- [x] Cloudflare Workers Free / $0 / Current planを管理画面で確認。
- [x] 本番・プレビューのSecretを設定し、両方をFail closedにした（APIで確認）。
- [x] 本番・ハッシュURLで認証とファイル保護を確認。ブランチエイリアス・プレビューデプロイは存在しない。
- [x] 無料枠超過時の提供停止を設定。有料プラン・API・独自ドメインの購入なし。

詳細は [限定提供の手順](private-deployment.md) を参照。

## メモリに関する残存リスク

配布版のheap最大値は約4GB。60秒のWorker終了は暴走時間を抑えるが、短時間のメモリ急増やブラウザタブの終了まで保証するものではない。学校用途で厳密な上限が必要な場合、たとえば512MBの `MAXIMUM_MEMORY` を設定したエンジンをビルドし、対象端末で検証する。JS引数を足すだけで上限を変更できるとは主張しない。
