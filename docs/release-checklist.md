# リリースチェックリスト

リリースごとに確認する項目。実施済みの検証と未検証の環境は[検証結果](verification.md)に記録する。

## ビルドと動作

- `npm ci` と `npm run build` が成功する。
- `npm test`、エンジン入力ソースのPythonテスト、Chromium/WebKitのE2Eが成功する。
- 入力、ファイル読込・保存、3D操作、STL出力、エラー後の復旧を確認する。
- 対象実端末で表示・操作・ファイル保存・メモリ使用を確認する。

## 配布ソースとライセンス

- エンジンの入力ソース、toolchain、変更内容、ライセンスを対応ソースとともに提供する。
- バイナリ、分割ソース、結合後アーカイブのSHA-256を確認する。
- アプリのソースZIPが配布する実装に対応し、構築手順とlockfileを含む。
- ソースとライセンスのリンクが有効である。
- 認証情報、ログ、ローカル成果物が配布ファイルに含まれていない。

## デプロイ

- HTTPS、WASMのMIME、CSP、キャッシュ設定を確認する。
- 認証を使う場合、本番・プレビューのSecretとFail closedを確認する。
- すべての配信URLで未認証・誤認証を拒否し、認証後に生成・保存できる。
- 配置先のプランと使用量上限を確認する。

詳細は[デプロイと認証](private-deployment.md)を参照。
