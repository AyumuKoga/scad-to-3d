# OpenSCADのコードをブラウザで3D表示し、STLとして保存する方法

OpenSCADのコードを貼り付けて、ブラウザ上で形を確認し、3Dプリント用のSTLを保存できる「SCAD → 3D」を用意しました。

3Dの形状計算にはOpenSCADのWebAssembly版、表示にはThree.jsを使用しています。OpenSCADの公式サイト・公式サービスではありません。

## ツールを使う

このツールは、記事を購入しなくても利用できます。有料部分は、下に記載した制作手順や解説です。

- サイト：https://scad-to-3d-private.pages.dev/
- ユーザー名：scad
- パスワード：【掲載する共通パスワードを入力】

1. サイトを開き、上記のユーザー名とパスワードを入力します。
2. サンプルを選ぶか、OpenSCADコードを貼り付けます。
3. 「3Dモデル生成」を押します。
4. 形を確認し、「STLをダウンロード」で保存します。

目盛りと寸法表示はcm/mmで切り替えられます。STLはスライサーでmmとして読み込んでください。画面上の単位変更でSTLの大きさは変わりません。

## 利用環境と制限

WebGL2に対応したChrome・Edge・Safari等のブラウザが必要です。端末によって扱えるモデルの複雑さが異なります。全機種での動作を保証するものではありません。

入力は200KB以下、生成は1回60秒以内、出力STLは25MB以下です。外部ファイルを読み込むinclude・use・import・surfaceと、フォントを必要とするtextは対象外です。デスクトップ版OpenSCADの全機能を備えたものではありません。

複雑な形状では処理が終了できない場合があります。コードは必要に応じて「コード保存」から保存してください。ブラウザへのコードの自動保存はありません。

生成したモデルは、印刷前にスライサーで寸法や形状を確認してください。用途に必要な強度や安全性は、別途確認してください。
